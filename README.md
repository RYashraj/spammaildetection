# 📧 Spam Email & SMS Detection Project

This project builds a Machine Learning model to detect whether an email or SMS message is "Spam" or "Ham" (Safe). It uses Natural Language Processing (NLP) techniques to clean the text, TF-IDF for vectorization, and a Multinomial Naive Bayes classifier.

The final product is wrapped in a clean, user-friendly Streamlit web interface.

## 📁 Folder Structure

```
PBLPROJ/
│
├── data/
│   ├── spam.csv                 # Raw dataset (must be downloaded manually)
│   └── cleaned_spam.csv         # Generated by Phase 1
│
├── models/
│   ├── vectorizer.pkl           # TF-IDF vocabulary (Generated by Phase 2)
│   ├── train_test_splits.pkl    # Data splits (Generated by Phase 2)
│   └── spam_model.pkl           # Trained Naive Bayes model (Generated by Phase 3)
│
├── plots/                       # EDA visualization charts (Generated by Phase 2)
│
├── phase1_data_preparation.py   # Script: Clean text, lemmatize, encode labels
├── phase2_eda_vectorization.py  # Script: EDA graphs, TF-IDF, data splitting
├── phase3_modeling.py           # Script: Train & tune MultinomialNB model
├── app.py                       # Streamlit UI (Phase 4)
│
├── requirements.txt             # Python dependencies
└── spam_email_detection_project_plan.md  # Project phases & plan
```

## 🚀 Setup & Installation

**1. Clone the repository**
```bash
git clone https://github.com/RYashraj/spammaildetection.git
cd spammaildetection
```

**2. Create and activate a Virtual Environment (Recommended)**
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On Mac/Linux:
source venv/bin/activate
```

**3. Install Dependencies**
```bash
pip install -r requirements.txt
```

**4. Download the Dataset**
*   Download the **SMS Spam Collection** dataset from [Kaggle](https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset).
*   Extract the `spam.csv` file and place it inside the `data/` folder.

## ⚙️ Running the Pipeline (Optional)
If you want to train the model yourself from scratch, run the scripts in order:

```bash
python phase1_data_preparation.py
python phase2_eda_vectorization.py
python phase3_modeling.py
```
*(Note: Pre-trained models might already be pushed to the repository, so you can skip directly to running the app if `models/spam_model.pkl` exists).*

## 💻 Running the Web App

To launch the Streamlit interface and test the spam detector live:

```bash
streamlit run app.py
```

This will open a local server in your web browser (usually at `http://localhost:8501`). Paste any text into the box to see if the AI classifies it as Spam or Ham!
